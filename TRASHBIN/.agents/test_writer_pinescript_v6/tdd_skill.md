# Test-Driven Development (Specialist Reference)
Source: C:\Users\gocha\.gemini\config\plugins\agent-skills\skills\test-driven-development\SKILL.md

Core Methodology:
1. Discover the stack first: Use the project's own test framework, commands, and conventions.
2. Formulate tests with explicit authoritative sources of truth (specifications, references, mathematical properties).
3. Self-contained & independent: Each test sets up its own state and cleans up after itself.
4. Adversarial verification: Test boundary conditions, invalid inputs, edge cases, special characters, and stress limits.
5. Real runtime execution: Execute against genuine browser/server runtime with zero mocking of assertions.
